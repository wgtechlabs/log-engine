## LoggerConfig

Configuration options for the logger.

```typescript
interface LoggerConfig {
  mode?: LogMode;
  level?: LogLevel;                        // Deprecated
  environment?: string;
  outputHandler?: LogOutputHandler;
  outputs?: OutputTarget[];
  enhancedOutputs?: EnhancedOutputTarget[];
  suppressConsoleOutput?: boolean;
  advancedOutputConfig?: AdvancedOutputConfig;
  format?: LogFormatConfig;
}
```

| Property | Type | Description |
|----------|------|-------------|
| `mode` | `LogMode` | Log mode controlling output behavior (recommended) |
| `level` | `LogLevel` | Legacy minimum log level (deprecated, use `mode`) |
| `environment` | `string` | Optional environment identifier |
| `outputHandler` | `LogOutputHandler` | Custom output handler function |
| `outputs` | `OutputTarget[]` | Array of output targets |
| `enhancedOutputs` | `EnhancedOutputTarget[]` | Enhanced outputs with advanced configuration |
| `suppressConsoleOutput` | `boolean` | Whether to suppress default console output |
| `advancedOutputConfig` | `AdvancedOutputConfig` | Advanced built-in handler configuration |
| `format` | `LogFormatConfig` | Format customization options |

## RedactionConfig

Configuration for automatic data redaction.

```typescript
interface RedactionConfig {
  enabled: boolean;
  sensitiveFields: string[];
  contentFields: string[];
  maxContentLength: number;
  redactionText: string;
  truncationText: string;
  deepRedaction: boolean;
  customPatterns?: RegExp[];
}
```

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `enabled` | `boolean` | `true` | Whether redaction is enabled globally |
| `sensitiveFields` | `string[]` | 50+ fields | Field names to redact (case-insensitive) |
| `contentFields` | `string[]` | 9 fields | Field names to truncate |
| `maxContentLength` | `number` | `100` | Max length before truncation |
| `redactionText` | `string` | `[REDACTED]` | Replacement text for redacted values |
| `truncationText` | `string` | `... [TRUNCATED]` | Text appended to truncated content |
| `deepRedaction` | `boolean` | `true` | Recursively scan nested objects |
| `customPatterns` | `RegExp[]` | `undefined` | Custom regex patterns for field detection |

## LogCallOptions

Options for individual log method calls.

```typescript
interface LogCallOptions {
  emoji?: string;
}
```

Set `emoji` to a specific string to override, or `''` to suppress for that call.

  debugRaw(message: string, data?: LogData, options?: LogCallOptions): void;
  infoRaw(message: string, data?: LogData, options?: LogCallOptions): void;
  warnRaw(message: string, data?: LogData, options?: LogCallOptions): void;
  errorRaw(message: string, data?: LogData, options?: LogCallOptions): void;

## Output Target Types

```typescript
type BuiltInOutputHandler = 'console' | 'silent' | 'file' | 'http';
type OutputTarget = BuiltInOutputHandler | LogOutputHandler;
type EnhancedOutputTarget =
  | BuiltInOutputHandler
  | LogOutputHandler
  | { type: 'file'; config: FileOutputConfig }
  | { type: 'http'; config: HttpOutputConfig };
```
