# Log Engine

Log Engine is a lightweight, zero-dependency logging library for Node.js, built because logging should protect sensitive data and just work — without complex configs or security afterthoughts.

Through automatic environment detection, **built-in PII redaction**, **configurable output routing**, color-coded console output, and full TypeScript support, it delivers enterprise-grade logging for Discord bots, web servers, APIs, and any server-side application.

## How It Works

<Steps>
  <Step title="Environment Detection">
    Log Engine automatically detects your environment using `NODE_ENV` and sets appropriate log levels for optimal performance.
  </Step>
  <Step title="Message Filtering">
    When you call logging methods, messages are filtered based on the configured severity level — only messages at or above the set level are displayed.
  </Step>
  <Step title="Formatting">
    Each log message is instantly formatted with precise timestamps in both ISO and human-readable formats.
  </Step>
  <Step title="Colorized Output">
    Messages are output to the console with colorized level indicators and timestamps — errors in red, warnings in yellow, info in blue, and debug in purple.
  </Step>
</Steps>

## Breaking Changes Notice

<Warning>
  **v3.0.0 Breaking Change**: The legacy `level` configuration will be removed in v3.0.0. If you're using `LogEngine.configure({ level: LogLevel.DEBUG })`, migrate to `LogEngine.configure({ mode: LogMode.DEBUG })`. See the [Migration Guide](/guides/migration) for details.
</Warning>
